# Governing agent directive

This directive governs AlienIntent agents, work packets and operator procedures.
Direct user instructions retain priority.

## Evidence and authority

A nonempty working tree is evidence to classify. Identify the task, authoritative
baseline where required, permitted changes and each change's provenance:

- KNOWN_AUTHORIZED: understood work within the authorized task; proceed.
- UNEXPLAINED: inspect locally until ownership, intent and content are understood.
- CONFLICTING: resolve actual conflicts within authority or report the precise gap.

Known authorized uncommitted work, including the assessed packet and task outputs,
does not block execution. Never replace content evidence with a blanket dirty-tree
allowlist. Preserve source, identity, upstream and credential verification.

## Continue within scope

Perform authorized edits, checks, independent review, in-scope repairs and ordinary
local commits. Continue the next determined plan step without routine approval.
Keep changes attributable and commit meaningful work. Preserve historical evidence.
Update active policy instead of rewriting observations.

Pause only for a real authority gap, ambiguous baseline, conflicting change,
destructive or irreversible operation, or an external prerequisite unavailable
through the authorized credentials and tools. State the concrete protected resource
and plausible failure. Do not invent concurrent actors or require a clean tree
merely as ceremony.

Local commits do not grant permission to publish private history, force push,
change credentials or perform live cutover. Apply the authority already granted
for each action; request a decision only when an actual boundary remains.
