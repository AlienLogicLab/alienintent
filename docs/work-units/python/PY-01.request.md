## Repository layout — fixed by Founder decision, not delegated

The layout is a binding Founder decision of 2026-09-19. The implementation agent
does not choose, vary or optimize it:

```text
pyproject.toml
src/alienintent/__init__.py
src/alienintent/execution_coordination/
src/alienintent/invocation_runtime/
src/alienintent/context_assembly/
src/alienintent/evidence_learning/
src/alienintent/installation/
src/alienintent/control_plane/
src/alienintent/composition/
tests/
tools/fitness/
```

Each of the five FD-02 modules contains `domain/`, `application/`, `ports/` and
`adapters/`. The Python package namespace is `alienintent` and the import root is
`src/alienintent`. Control Plane is application orchestration, not a state-owning
context. `composition/` is the composition root and the only place concrete
adapters and configuration are wired into ports.

Node keeps `src/config/`, `src/domain/`, `src/github/`, `src/providers/`,
`src/runtime/`, plus `test/` and `scripts/`, and must not be moved or renamed.
Python source appearing in the npm package is accepted; the frozen Node package
metadata must not be edited to remove it. At Python Sovereignty, Node is deleted
and the Python tree is not relocated.
