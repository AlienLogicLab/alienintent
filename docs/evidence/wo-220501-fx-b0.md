them. They are still included in the zero-effect snapshot.

Every asset records its sha256, git blob id, size, mode and mtime (mtime is context only), plus:

- consumers: sibling bootstrap assets that import it or name it, user units whose lines contain its
  absolute path (and whether a `*.wants` link enables them), running processes whose argv contains the
  exact path, and repository files that name it with a qualified `alienintent-bootstrap/<path>` reference;
- a count of repository files that mention only the basename. These are not attributed, because
  basenames can collide with unrelated files;
- provenance: repository paths holding identical bytes at the pinned revision, repository commits that
  added or removed that exact blob, and the bootstrap tests that reference the asset.
