### Fixture inputs (durable state only; `tmp_path` or `--output` root, never a live profile)
- **Store and evidence.** One `SQLiteOperationalStore` (`execution_coordination/adapters/sqlite_store.py`) and one `LocalEvidenceRepository` (`evidence_learning/adapters/local_evidence_repository.py`), composed through `composition/upstream_profile.py` `UpstreamProfile` as FX-U5 does.
- **Design gate.** A U5 `upstream:design:<key>` aggregate driven through `DesignAdmission.inspect`/`record_review`, in four states: VERIFIED with the current vector; VERIFIED and then invalidated to STALE through a changed vector (`DesignAdmission.check`); REVIEW_REQUIRED (no independent review); and absent. `DesignReadiness.admit` is the only read.
- **Candidate documents (hand-authored; validation only).** A `CompilationCandidate` JSON document, with the fields of `#/contracts/2/ports/1` and `/state`: stable `unit_key`, BIU identity, `BiuContract` canonical payloads (built with the existing `execution_coordination.domain.contract.BiuContract` and `BudgetPolicy` constructors), requirement/acceptance/verification/evidence obligation IDs and extents, `design_ref`, fixed decisions, edges `{from, to, predicate}` and a coverage manifest. Variants:
  - valid acyclic, fully resolved graph;
  - a cycle A→B→C→A;
  - an edge to an absent endpoint;
  - an edge with an empty/absent predicate;
  - a contract missing one required `BiuContract` field (for example `required_evidence`);
  - one uncovered obligation in each of the four categories;
  - a fixed decision absent from, or conflicting with, the verified design's decisions for the linked requirement;
  - an open upstream question (`AmbiguityService.questions(OPEN)`) on a linked requirement.
- **Dependency authority (013-dependency-authority).** `factory:<id>` aggregates written through `FactoryCoordinator`'s existing encoding: predecessor P1 at `LifecycleStage.DONE`, and predecessor P2 non-terminal (IMPLEMENT). A decoy Issue projection `{P1: OPEN, P2: CLOSED}` is placed in the candidate's projection metadata. A contract declares `dependencies=(P1, P3)` while the edge set names only P1.
