# AlienIntent name and organization

Date: 2026-09-18

The permanent project name is **AlienIntent**, by **Alien Logic Lab**. The canonical
repository is `AlienLogicLab/alienintent`. AlienIntent keeps autonomous software
engineering aligned with intent, evidence, and outcomes.

AlienIntent was previously developed under the working name B-DISP, a provisional
name derived from the dispatcher. Its scope now includes intent, authority,
verification, recovery and operational completion beyond dispatch.

Active product names, commands and examples use AlienIntent. Historical records
may retain their original names. The public command is `alienintent`; `b-disp`
remains a temporary compatibility alias that can be removed after installations
migrate their launch commands.

The rename does not change lifecycle or persisted-state semantics. Existing
`B-DISP:` Issue markers, role aliases, lane keys, invocation IDs, closure records,
resource branch names and ownership directories remain compatible. Do not rewrite
historical state for naming consistency. Repository identity changes require
explicit installation validation before resuming unresolved work.

The supported initial topology aligns repository owner, Project owner, App owner
and App installation account in one organization, with one repository, one Project
and one running profile. REVIEW is lifecycle context; there is no MERGE state.
