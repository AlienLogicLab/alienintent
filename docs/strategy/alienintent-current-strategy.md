# AlienIntent current strategy

Date: 2026-09-18. Current name: **AlienIntent**, by Alien Logic Lab.

AlienIntent keeps autonomous software engineering aligned with intent, evidence,
and outcomes. It remains reusable standalone infrastructure. See the
[naming decision](../decisions/2026-09-18-alienintent-name-and-organization.md).

The immediate milestone is a genuine live self-hosting proof: organization-owned
repository, Project, and App; independent producer and verifier identities;
correlated authenticated results; disposable worktrees; acceptance, closure, DONE,
and durable recovery. An offline rehearsal does not satisfy this milestone.

Once that proof passes, the near-term sequence is autonomous backlog materialization,
Context Engineering v1, Verification Contract v1, Model Routing v1, Quality Evidence
Store v1, Trajectory Observability v1, execution profiles, and harness versioning.
Then begin substantial FactoryChecks field proving through AlienIntent under its
applicable work authority. FactoryChecks remains unchanged during the rename and
self-hosting work. RAI remains unwired.

The release strategy is self-hosting, substantive field use, evidence-based
hardening, external installation proof, then broad public release. A public source
repository is not a claim that these release gates have passed.

This is the current naming and sequencing summary. Dated source research, earlier
strategy proposals, and historical governance records may retain B-DISP to preserve
provenance; their proposed capabilities do not become implemented capabilities or
unbounded execution authority through this summary.
