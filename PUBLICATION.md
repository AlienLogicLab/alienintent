# Public Publication Boundary

`AlienLogicLab/alienintent` is the curated public representation of AlienIntent.

Public publication is deliberate. Material is eligible for this repository only when it is appropriate for external consumption.

## Public

Examples include:

- curated source intended for distribution;
- public architecture and usage documentation;
- releases;
- installation instructions;
- contribution guidance;
- public issue intake;
- examples and demonstrations that contain no private operational context.

## Not public

The public repository must not contain:

- private engineering history;
- internal requirements, planning, or continuity records not explicitly selected for publication;
- worker prompts, packets, temporary artifacts, or operational evidence;
- credentials, keys, tokens, secrets, or credential-bearing configuration;
- private infrastructure details;
- internal evaluation corpora or model-session records.

The engineering repository is authoritative for active development. This repository is authoritative only for what Alien Logic Lab has deliberately published.
